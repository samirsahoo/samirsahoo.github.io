Strategic AI architecture handbook

Enterprise AI & Agentic AI Knowledge Hub

Understand the concepts. Draw the architecture. Review with confidence.

Strategic AI architecture explained simply: LLMs and model selection, the enterprise AI stack, RAG and GraphRAG, vector databases, evaluation, agents, MCP and multi-agent patterns, Spring AI, AI security and governance — with diagrams, system designs and review questions.

Choose a learning pathReview & self-check

This handbook explains enterprise AI the way an architect needs it: what each building block does, why it exists, how the pieces fit into a system, and what can go wrong. Every article follows the same structure: a simple definition, the problem it solves, diagrams of the architecture and the request flow, trade-offs, common mistakes, and review questions with answers. Key flows are drawn as interactive Archify diagrams you can zoom, explore by guided view and export.

The handbook has six modules and a review section:

  1. LLM Foundations & the Enterprise AI Stack: AI engineering fundamentals, how large language models are trained and work, inference and its optimisation, prompting, fine-tuning in depth, dataset engineering, evaluation methodology and pipelines, model selection, the reference stack, a progressive AI application architecture, user feedback, on-premise and hybrid deployment, LLMOps, GenAI adoption strategy and hybrid AI in financial services.
  2. RAG, Vector Databases & GraphRAG: retrieval-augmented generation from first principles to hybrid search, reranking, GraphRAG and evaluation, plus a full system design.
  3. Agentic AI, MCP & Multi-Agent Systems: generative vs agentic AI, the five levels and the SPAR loop, the agent loop, tool calling, planning and failure modes, MCP and the agent protocol stack (A2A, AG-UI, Agent Skills), workflow patterns, multi-agent topologies, memory, harnesses, computer use, agent identity, reliability, strategy and a practical agent-building playbook (opportunity scoring, the A.G.E.N.T. framework).
  4. Spring AI, AI Security & Governance: building all of the above in Java with Spring AI 2.0, then securing and governing it.
  5. Agent Frameworks & Platforms: LangGraph, OpenAI Agents SDK, Claude Agent SDK, Google ADK, Microsoft Agent Framework, CrewAI, Embabel, LangChain4j and more — plus managed agent platforms and how to choose.
  6. Claude for Engineering & the SDLC: the Claude model family and how to choose model and effort, the Claude API for builders, Claude Code for development teams, a phase-by-phase SDLC playbook and the practices for using Claude safely, cheaply and well.
  7. Review: an architecture review framework, review questions by module and a quick-reference sheet.
