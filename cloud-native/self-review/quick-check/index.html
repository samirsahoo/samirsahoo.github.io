1. Kubernetes architecture#

Read: Kubernetes architecture.

What does “declarative” mean in Kubernetes? You store desired state as API objects; controllers continuously reconcile actual state toward it.

Which component is the only one that talks to etcd? The kube-apiserver.

What do the scheduler and the kubelet each do? The scheduler assigns Pods to nodes; the kubelet on each node runs the assigned Pods through the container runtime and reports status.

Why 3 or 5 etcd members? Raft needs a majority for quorum; odd sizes maximise tolerated failures (1 of 3, 2 of 5).

What is a CRD and an operator? A CRD adds a new API type; an operator is a controller that reconciles it to automate an application’s lifecycle.

What runtime interfaces does Kubernetes use? CRI (runtimes), CNI (networking), CSI (storage).

How often does Kubernetes release, and how should you upgrade? About three minor releases a year; upgrade one minor version at a time, control plane before nodes.

2. Workloads, scheduling and storage#

Read: Workloads & scheduling.

Deployment vs StatefulSet vs DaemonSet? Stateless replicas; stable identity with per-Pod storage; one Pod per node.

Readiness vs liveness vs startup probes? Readiness gates traffic; liveness restarts stuck containers; startup delays other probes until the app has started.

What happens when a container exceeds memory vs CPU limits? Memory: OOM-killed. CPU: throttled.

What are the QoS classes? Guaranteed, Burstable, BestEffort.

What do taints and tolerations do? Taints repel Pods from nodes; only Pods with matching tolerations may be scheduled there.

HPA vs KEDA vs VPA vs Karpenter? Replicas on metrics; replicas on events including scale to zero; right-sizing requests; node provisioning and consolidation.

What chain provides persistent storage? PVC → StorageClass → CSI driver → PersistentVolume.

What is in-place Pod resize? Changing CPU and memory of running containers without restarting the Pod — stable since Kubernetes 1.35.

3. Networking and service mesh#

Read: Networking, Service mesh.

What does a CNI plugin do? Assigns Pod IPs and connects Pods across nodes according to the network model.

Why do Services exist? To provide stable virtual IPs and DNS names for changing sets of Pods.

Name the Service types. ClusterIP, NodePort, LoadBalancer, headless, ExternalName.

What are the Gateway API’s main resources? GatewayClass, Gateway, and routes such as HTTPRoute and GRPCRoute.

What happened to ingress-nginx in 2026? The community controller was retired in March 2026; migrate to the Gateway API or a maintained controller.

How do you isolate a namespace’s network? Default-deny NetworkPolicy plus explicit allows, including DNS.

What does a service mesh add? mTLS identity, traffic management, resilience features and telemetry without code changes.

What are ztunnel and waypoints? In Istio ambient mode: a per-node L4 mTLS proxy, and optional L7 proxies where needed.

4. Kubernetes security#

Read: Kubernetes security.

What are the 4Cs? Cloud, cluster, container, code.

Which three checks does every API request pass? Authentication, authorisation (RBAC) and admission control.

What does Pod Security “restricted” require? Non-root, no privilege escalation, dropped capabilities, seccomp RuntimeDefault, no host namespaces.

Kyverno, Gatekeeper or ValidatingAdmissionPolicy? Kyverno — YAML policies incl. mutation and image verification; Gatekeeper — Rego; VAP — built-in CEL rules without webhooks.

Why aren’t Secrets secure by default? They are base64-encoded; use etcd encryption at rest, RBAC and external secret stores.

What secures the supply chain? Minimal images, scanning, SBOMs, SLSA provenance, cosign signatures and verification at admission; deploy by digest.

What is workload identity? Mapping Kubernetes service accounts to cloud IAM roles so Pods get short-lived cloud credentials without stored keys.

5. Containers, Kubernetes operations and OpenShift#

Read: Containers & Docker, Kubernetes in practice, OpenShift.

What isolates a container? Namespaces, cgroups, and security mechanisms (seccomp, capabilities, LSMs).

Why multi-stage builds? Smaller, safer runtime images without build tools.

Docker vs containerd vs Podman? Developer platform built on containerd; Kubernetes runtime via CRI; daemonless rootless engine.

Kustomize vs Helm? Overlay patches for your own YAML vs versioned, templated packages.

What is Cluster API? Declarative lifecycle management of Kubernetes clusters.

What does OpenShift add to Kubernetes? An integrated supported platform: RHCOS, CRI-O, SCCs, Routes, OLM, Pipelines (Tekton), GitOps (Argo CD), Service Mesh, Virtualization, Developer Hub.

What is an SCC? A Security Context Constraint controlling Pod privileges in OpenShift.

6. Helm, CI/CD, GitOps and release orchestration#

Read: Helm, CI/CD, GitOps, Release orchestration.

Chart vs values vs release? Template package; configuration; installed instance with history.

Name three Helm 4 changes. Server-side apply by default for new releases, WebAssembly plugins, install by digest (also renamed flags, kstatus waiting).

Continuous delivery vs continuous deployment? Every change releasable vs every passing change released automatically.

Why build once and promote? The tested artifact is the released artifact.

Blue-green vs canary? Full switch between two environments vs gradual traffic shift with analysis.

Name the DORA metrics. Deployment frequency, lead time for changes, change failure rate, failed deployment recovery time.

What are the OpenGitOps principles? Declarative, versioned and immutable, pulled automatically, continuously reconciled.

Argo CD vs Flux? Argo CD: UI, ApplicationSets, renders Helm; Flux: controller toolkit, real Helm releases, OCI-native. Both CNCF graduated.

How do you promote between environments with GitOps? A pull request that updates the target environment’s desired state (image digest or chart version).

What does release orchestration add? Coordination of multi-team, multi-tool releases with gates, approvals, change management and audit evidence.

What is the difference between Digital.ai Release and Deploy? Release orchestrates the end-to-end process; Deploy performs model-driven deployments, especially to non-Kubernetes targets.

7. Platform engineering and developer experience#

Read: Fundamentals, IDPs, DevEx.

What is platform engineering? Building internal self-service platforms that reduce cognitive load and embed guardrails.

What does “platform as a product” mean? Developers are customers; adoption is earned; outcomes are measured.

What is a golden path? An opinionated, supported, end-to-end way to do a common task with best practices built in.

Name the Team Topologies team types. Stream-aligned, platform, enabling, complicated-subsystem.

IDP vs developer portal? The platform (automation, APIs) vs its user interface.

Name Backstage’s core features. Software catalog, templates, TechDocs, plugins.

What does Crossplane do? Provides Kubernetes-style APIs and compositions to provision infrastructure from claims.

Name the CNCF maturity model aspects. Investment, adoption, interfaces, operations, measurement.

What are the three DevEx dimensions? Feedback loops, cognitive load, flow state.

Why combine surveys and system metrics? Systems show where time goes; surveys show friction and satisfaction.

8. SRE, observability, resilience and FinOps#

Read: SRE, Observability, Resilience & DR, FinOps.

SLI vs SLO vs SLA? Measurement; target; contract.

Downtime allowed by 99.9% per 30 days? About 43 minutes.

Why burn-rate alerts? They page only when the error budget is threatened, with fewer false alarms.

What does an incident commander do? Coordinates the response and communication; does not debug.

What makes a postmortem blameless? Focus on systems and decisions, psychological safety, owned actions.

Monitoring vs observability? Known checks vs exploring correlated telemetry to answer new questions.

Name the telemetry signals. Metrics, logs, traces, profiles (and events).

What does the OTel Collector do? Receives, processes (sample, redact, enrich) and exports telemetry.

RED vs USE? Rate-errors-duration for services; utilisation-saturation-errors for resources.

RPO vs RTO? Maximum data loss vs maximum downtime.

Name four DR strategies. Backup & restore, pilot light, warm standby, active-active.

What is chaos engineering? Controlled experiments that inject failure to test resilience hypotheses.

What are the FinOps phases? Inform, Optimize, Operate.

What is FOCUS? A standard billing data format across providers.

How is Kubernetes cost allocated? By splitting node and shared costs by Pod requests/usage, using namespaces and labels (OpenCost).

Name three cost levers. Rightsizing, autoscaling/bin-packing, spot, commitments, non-prod schedules.
