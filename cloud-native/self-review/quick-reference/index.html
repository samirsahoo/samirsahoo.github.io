Kubernetes objects at a glance#

Need Object
Stateless app Deployment (+ HPA, PDB)
Stateful app StatefulSet + PVC (or operator / managed service)
Per-node agent DaemonSet
Batch / scheduled Job / CronJob
Stable address Service
North-south traffic Gateway + HTTPRoute
Config / secrets ConfigMap / Secret (+ External Secrets)
Isolation & budgets Namespace, ResourceQuota, LimitRange, NetworkPolicy
Availability during drains PodDisruptionBudget
New API types CRD + operator

kubectl essentials#

kubectl get pods -n shop -o wide            # what is running where
kubectl describe pod <pod> -n shop          # events and reasons
kubectl logs deploy/orders -n shop -f       # logs
kubectl events -n shop --types=Warning      # recent problems
kubectl diff -f k8s/                        # preview changes
kubectl rollout status deploy/orders        # watch a rollout
kubectl rollout undo deploy/orders          # roll back
kubectl debug -it <pod> --image=busybox     # ephemeral debug container
kubectl auth can-i delete pods --as=jane    # check RBAC
kubectl top pods -n shop                    # resource usage

Secure defaults#

Area Default
Pod security Namespace label pod-security.kubernetes.io/enforce: restricted
Container non-root, read-only root FS, drop ALL capabilities, seccomp RuntimeDefault
Network Default-deny NetworkPolicy + explicit allows (incl. DNS)
Images Minimal base, scanned, signed, SBOM, deployed by digest
Secrets External store + External Secrets Operator; etcd encryption at rest
Access OIDC humans, least-privilege RBAC, read-only prod, workload identity for Pods

Delivery#

Topic Rule of thumb
Artifacts Build once, sign, promote by digest
Packaging Helm for packages, Kustomize for overlays
Deployment GitOps pull (Argo CD / Flux); folders per environment, not branches
Rollout Canary with automated analysis (Argo Rollouts / Flagger)
Secrets in Git Never plaintext: External Secrets, Sealed Secrets or SOPS
Governance Risk-based automated approvals; orchestration for multi-team releases
DORA Deploy frequency, lead time, change failure rate, recovery time

Platform engineering#

Concept One-liner
Platform as a product Developers are customers; adoption is earned
Golden path Opinionated supported route with guardrails
IDP planes Developer control, integration & delivery, resources, observability, security
Portal Backstage: catalog, templates, TechDocs, plugins
Infra APIs Crossplane / kro claims and compositions
DevEx Feedback loops, cognitive load, flow state
Maturity aspects Investment, adoption, interfaces, operations, measurement

SLO maths#

SLO Downtime / 30 days Error budget
99% 7.2 h 1%
99.5% 3.6 h 0.5%
99.9% 43 min 0.1%
99.95% 22 min 0.05%
99.99% 4.3 min 0.01%

Fast-burn page (99.9% SLO): burn rate ≥ 14.4 over 1 h and 5 min = 2% of monthly budget in one hour.

Observability#

Topic Rule of thumb
Standard OpenTelemetry SDKs + Collector (agent DaemonSet + gateway)
What to watch RED for services, USE for resources, SLIs for users
Alerts On SLO burn, with runbooks
Cardinality No unbounded labels (user IDs, request IDs)
Sampling Tail sampling: keep errors and slow traces

DR strategies#

Strategy RPO RTO Cost
Backup & restore Hours Hours–days $
Pilot light Minutes Hours $$
Warm standby Seconds–minutes Minutes $$$
Active-active ~0 ~0 $$$$

FinOps levers#

Lever Notes
Rightsize requests Biggest win; VPA recommendations; in-place resize
Autoscale HPA/KEDA for Pods, Karpenter for nodes, scale non-prod to zero
Spot Stateless, batch, fault-tolerant workloads
Commitments After rightsizing, for steady baseline
Allocation Enforced labels + OpenCost + showback in portal
Unit economics Cost per order / customer / API call

Key 2025–2026 changes#

Change Impact
Kubernetes 1.35: in-place Pod resize stable; cgroup v1 removed by default; last release for containerd 1.x Plan node OS/runtime upgrades
Kubernetes 1.36: user namespaces GA, DRA improvements, volume group snapshots stable Better isolation, GPUs, backups
ingress-nginx retired (March 2026) Migrate to Gateway API or another controller
Helm 4 (Nov 2025) Server-side apply, Wasm plugins, digest installs
Istio ambient GA Sidecarless mesh with lower overhead
OpenTelemetry graduated (2026); profiles in alpha OTel as the default telemetry standard
Docker Hardened Images free (Dec 2025) Easier minimal, attested base images
