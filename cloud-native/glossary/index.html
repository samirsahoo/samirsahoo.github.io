Glossary

Short definitions of the cloud native, platform engineering, SRE and FinOps terms used across the handbook, with links to the articles that explain them.

  • 3 min read
  • Reviewed November 1, 2026
  • #Reference

Definitions are deliberately short. Follow the links for the full explanation.

A–C#

Admission control
Checks that validate or mutate API objects before they are stored. See Kubernetes security.
Argo CD
A GitOps controller that syncs Kubernetes clusters with Git. See GitOps.
Argo Rollouts
Progressive delivery controller for canary and blue-green rollouts. See CI/CD.
Backstage
An open-source developer portal framework (catalog, templates, docs, plugins). See IDPs.
Blue-green deployment
Switching all traffic between two complete environments. See CI/CD.
Burn rate
How fast an error budget is being consumed relative to the SLO. See SRE.
Canary release
Gradually shifting traffic to a new version while analysing metrics. See CI/CD.
cgroups
Linux control groups that limit a process’s resources. See Containers.
CNI / CRI / CSI
Standard interfaces for networking, container runtimes and storage. See Architecture.
Crossplane
A Kubernetes-based control plane for provisioning infrastructure through APIs. See IDPs.
Custom resource / operator
A new API type and the controller that automates it. See Architecture.

D–G#

Developer experience (DevEx)
How developers perceive their work environment: feedback loops, cognitive load, flow. See DevEx.
Digital.ai Release / Deploy
Enterprise release orchestration and model-driven deployment tools. See Release orchestration.
DORA metrics
Deployment frequency, lead time, change failure rate, recovery time. See CI/CD.
Dynamic Resource Allocation (DRA)
Kubernetes API for requesting GPUs and other devices. See Workloads.
eBPF
Programs running safely in the Linux kernel, used for networking, security and observability. See Networking.
Error budget
The allowed unreliability, 1 − SLO. See SRE.
etcd
The distributed key-value store holding Kubernetes state. See Architecture.
FinOps
Practice of managing cloud value through engineering–finance collaboration. See FinOps.
FOCUS
FinOps Open Cost and Usage Specification for billing data. See FinOps.
Gateway API
The successor to Ingress for routing traffic into and within clusters. See Networking.
GitOps
Declarative desired state in Git, pulled and reconciled by agents. See GitOps.
Golden path
An opinionated, supported way to perform a common task. See Platform engineering.

H–O#

Helm
The Kubernetes package manager (charts, values, releases). See Helm.
HPA / VPA / KEDA
Autoscalers for replicas, requests and event-driven scaling. See Workloads.
Internal developer platform (IDP)
Integrated tools, APIs and golden paths for self-service delivery. See IDPs.
Karpenter
A node autoscaler that provisions right-sized nodes and consolidates. See Workloads.
Kyverno
A Kubernetes-native policy engine. See Security.
NetworkPolicy
Rules restricting Pod traffic. See Networking.
Observability
Ability to understand system behaviour from telemetry. See Observability.
OpenShift
Red Hat’s enterprise Kubernetes platform. See OpenShift.
OpenTelemetry (OTel)
The vendor-neutral standard for telemetry. See Observability.

P–Z#

PodDisruptionBudget (PDB)
Limits voluntary disruptions to an application. See Resilience.
Pod Security Standards
Privileged, baseline and restricted security profiles. See Security.
RBAC
Role-based access control for the Kubernetes API. See Security.
RPO / RTO
Maximum acceptable data loss and downtime. See Resilience.
SBOM
Software bill of materials. See Security.
Service mesh
Infrastructure layer for mTLS, traffic control and telemetry. See Service mesh.
SLI / SLO / SLA
Indicator, objective and agreement for reliability. See SRE.
SLSA
Supply-chain Levels for Software Artifacts — build provenance framework. See Security.
Team Topologies
Model of team types and interactions. See Platform engineering.
Toil
Manual, repetitive, automatable operational work. See SRE.
