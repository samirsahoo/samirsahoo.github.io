About this handbook

Purpose, structure, conventions and versions of the Cloud Native & Platform Engineering Knowledge Hub.

Purpose#

The Cloud Native & Platform Engineering Knowledge Hub explains how modern platforms are built and run — simply, with diagrams and flows — for architects, platform engineers, SREs and developers. It is the companion to the Java & Software Architecture Knowledge Hub and the Enterprise AI & Agentic AI Knowledge Hub.

Structure#

  1. Kubernetes Architecture, Networking & Security
  2. Containers, OpenShift, Helm, GitOps & CI/CD (including release orchestration with Digital.ai)
  3. Platform Engineering, IDPs & Developer Experience
  4. SRE, Observability, Resilience & FinOps
  5. Self Review & Quick Check

Conventions#

Every article has a simple definition, the problem, core concepts with diagrams and flows, practical guidance, common mistakes, a quick check with answers, a summary and references. Key flows are interactive diagrams drawn with Archify; smaller diagrams are Mermaid, kept in version control next to the text.

Versions and currency#

Content was reviewed on 1 November 2026 against Kubernetes 1.36, Helm 4, Argo CD 3.x, Flux 2.x, OpenShift 4.21, OpenTelemetry (graduated, profiles in alpha) and Digital.ai Release 26.x. Cloud native tools move fast: check release notes before relying on version-specific details.
