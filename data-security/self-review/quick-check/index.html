1. Kafka fundamentals#

Read: Kafka architecture.

What is a Kafka partition? An ordered, append-only log. Topics are split into partitions for parallelism, and ordering holds only within one partition.

What decides which partition a record goes to? The record key, hashed by the partitioner. The same key always maps to the same partition, unless the partition count changes.

What is the ISR? The in-sync replicas: replicas fully caught up with the leader. Only these count towards acks=all.

What do RF=3 and min.insync.replicas=2 protect against? Losing one broker without losing acknowledged writes and without stopping writes.

Why disable unclean leader election? It can elect an out-of-sync replica and silently lose acknowledged data.

What replaced ZooKeeper, and since when exclusively? KRaft controllers (a Raft metadata quorum), exclusively since Kafka 4.0.

What do share groups add? Queue semantics: many consumers per partition, per-record acknowledgement, delivery counting. GA in Kafka 4.2.

What does a compacted topic keep? At least the latest record per key. Tombstones (null values) delete keys.

What is tiered storage for? Cheap long retention, by moving older segments to object storage.

2. Producers, consumers and guarantees#

Read: Producers, consumers & exactly-once.

At-most-once vs at-least-once? At-most-once commits before processing, so events can be lost. At-least-once commits after processing, so events can be duplicated.

What does the idempotent producer do? De-duplicates producer retries using a producer ID and sequence numbers.

What do Kafka transactions make atomic? Writes to multiple partitions plus consumer offset commits.

Does Kafka exactly-once cover a write to PostgreSQL? No. Use an idempotent consumer, or the outbox pattern.

What happens if processing exceeds max.poll.interval.ms? The consumer is considered failed, and its partitions are rebalanced to other members.

What is a dead-letter topic? Where records that fail permanently go, with error details, so the stream keeps moving.

What does KIP-848 change? Rebalancing becomes broker-coordinated and incremental (group.protocol=consumer), avoiding stop-the-world rebalances.

3. Event-driven architecture and contracts#

Read: Event-driven architecture and Schemas & event contracts.

Event vs command? An event is a past fact for unknown consumers. A command asks a specific receiver to act.

What is event-carried state transfer? Events carry the data consumers need, so consumers do not call back to the producer.

When orchestrate instead of choreograph? For multi-step business processes with compensation, SLAs and audit needs.

What fields should every event have? A unique ID, type and version, source, event time, subject or key, and correlation and trace IDs.

What does BACKWARD compatibility mean? New consumers can read data written with the previous schema, so you upgrade consumers first.

How do you make a breaking schema change? Publish a new major-version topic, run v1 and v2 in parallel, migrate consumers, then retire v1.

What does a data contract include beyond the schema? Semantics, quality rules, SLOs, ownership, classification and policies.

4. Stream processing#

Read: Stream processing.

Event time vs processing time? When the event happened, versus when the processor sees it. Use event time for correct business results.

What is a watermark? An estimate that no events older than T remain, which lets windows close.

Tumbling vs hopping vs session windows? Tumbling windows are fixed and non-overlapping. Hopping windows are fixed and overlapping. Session windows are bounded by inactivity gaps.

How does Flink recover state? From the latest checkpoint (a consistent snapshot of state plus source offsets).

When choose Kafka Streams over Flink? For Kafka-to-Kafka processing embedded in a microservice, with no separate cluster.

What did Flink 2.2 add for AI? ML_PREDICT model inference and VECTOR_SEARCH in Flink SQL.

5. Consistency and transactions#

Read: Consistency & consensus and Distributed transactions.

What does CAP really say? During a network partition, a replicated system must choose between consistency and availability.

What does PACELC add? Without a partition, there is still a latency versus consistency trade-off.

R + W > N means what? Read and write quorums overlap, so reads see the latest acknowledged write.

How many Raft nodes, and why? 3 or 5. A majority is needed, and odd sizes maximise tolerated failures.

What anomaly does snapshot isolation allow? Write skew.

What is the dual-write problem? Updating two systems without a shared transaction, so one can succeed while the other fails.

Why avoid 2PC across microservices? It blocks on coordinator failure, adds latency, lowers availability, couples services, and many systems do not support it.

What is TCC? Try (reserve, with expiry), then Confirm or Cancel.

6. Outbox, sagas, CQRS and event sourcing#

Read: Outbox, CDC & idempotency, Saga and CQRS & event sourcing.

How does the outbox pattern work? Write the state change and the event row in one local transaction, then relay outbox rows to the broker (polling or CDC).

Why prefer log-based CDC as the relay? Low latency, low database load and commit-order preservation.

How do you make a consumer idempotent? Record the event ID in the same transaction as the business change, or apply versioned, naturally idempotent updates.

What is a compensating transaction? A new business action that semantically undoes an earlier saga step.

What is a pivot step? The point of no return. Later steps must be retried until they succeed.

Which ACID property do sagas lack? Isolation. Mitigate with semantic locks, commutative updates and versioning.

What does CQRS separate? The write model (commands, invariants) from the read models (queries).

How is state rebuilt in event sourcing? By replaying the aggregate’s events, optionally from a snapshot.

How do you erase personal data from an event store? Crypto-shredding: delete the subject’s encryption key.

7. Data platforms and governance#

Read: Data platform architecture and Data governance.

What is a lakehouse? Open table formats on object storage, with ACID, time travel and one catalog, queried by many engines.

Name three Iceberg v3 features. Deletion vectors, row lineage, the VARIANT type, geospatial types, nanosecond timestamps and default values.

What are the medallion layers? Bronze (raw), silver (cleaned and conformed) and gold (business data products).

The four data mesh principles? Domain ownership, data as a product, a self-serve platform, and federated computational governance.

What is OpenLineage? An open standard for lineage events emitted by pipelines and engines.

Name four data quality dimensions. Completeness, validity, accuracy, consistency, uniqueness and timeliness.

What does BCBS 239 cover? Risk data aggregation and reporting: governance, accuracy, completeness, timeliness and adaptability.

8. Data security and privacy#

Read: Data security & privacy.

Tokenisation vs encryption? Tokens are random substitutes mapped in a vault. Encryption is reversible with a key. Tokenisation shrinks compliance scope.

What is envelope encryption? Data is encrypted with a DEK, and the DEK is encrypted with a KEK held in a KMS or HSM.

RBAC vs ABAC? RBAC grants by role. ABAC decides from attributes of the user, the data and the context.

Static vs dynamic masking? Static masking irreversibly changes copies (for test data). Dynamic masking hides values at query time based on the user.

Is pseudonymised data personal data under GDPR? Yes.

What does RBI require for payment data? Storage only in India.

9. Threat modelling and security architecture#

Read: Threat modelling and Security architecture.

The four threat-modelling questions? What are we working on? What can go wrong? What will we do about it? Did we do a good job?

STRIDE? Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege.

Privacy threat-modelling method? LINDDUN.

Zero trust in one sentence? Verify identity, device and context for every request. No implicit trust from network location.

Two new OWASP Top 10:2025 categories? A03 Software Supply Chain Failures and A10 Mishandling of Exceptional Conditions.

What is BOLA? Broken object-level authorisation: missing per-object access checks in APIs.

SBOM vs SLSA? An SBOM inventories components. SLSA defines build integrity and provenance levels.

Which NIST PQC standards were published in 2024? FIPS 203 (ML-KEM), FIPS 204 (ML-DSA) and FIPS 205 (SLH-DSA).

10. AI security#

Read: AI security.

What is indirect prompt injection? Malicious instructions hidden in content the model processes, such as documents, web pages or tool output.

Main design principle against prompt injection? Assume it succeeds. Limit what the model can access and do (least agency, user-scoped tools, approvals).

OWASP LLM06? Excessive Agency.

How should RAG enforce permissions? Filter retrieval by the user’s entitlements, using ACL metadata. Never rely on prompts.

ASI01 in the agentic Top 10? Agent Goal Hijack.

Two AI governance frameworks? The NIST AI RMF (with the GenAI profile) and ISO/IEC 42001.

11. FinTech regulations#

Read: FinTech regulations.

When did PCI DSS v4 future-dated requirements become mandatory? 31 March 2025.

Best way to reduce PCI scope? Tokenise PAN at the edge (hosted fields), and segment a minimal CDE.

DORA’s five pillars? ICT risk management, incident reporting, resilience testing, third-party risk and information sharing.

DORA initial notification for a major incident? Within 4 hours of classification, and no later than 24 hours from awareness.

PSD2 SCA factors? Two of knowledge, possession and inherence, with dynamic linking for remote payments.

PSD3/PSR status? Agreed in 2025, with texts published in 2026. Application is expected around 2027–28.

When do EU AI Act high-risk rules apply to credit scoring? From 2 December 2027, after the 2026 Digital Omnibus.

CERT-In requirements? Report incidents within 6 hours, and keep logs for 180 days in India.

What do the DPDP Rules 2025 phase in, and when? The Board immediately, Consent Managers from November 2026, and most obligations from May 2027.
