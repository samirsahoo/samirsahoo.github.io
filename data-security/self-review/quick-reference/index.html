Kafka production defaults#

Setting Value
replication.factor 3 (across 3 AZs, rack-aware)
min.insync.replicas 2
acks all
enable.idempotence true
unclean.leader.election.enable false
compression.type zstd or lz4
linger.ms / batch.size 5–20 ms / 64–256 KB
enable.auto.commit (business consumers) false; commit after processing
group.protocol consumer (KIP-848)
isolation.level (downstream of transactions) read_committed
Controllers 3 dedicated KRaft controllers

Delivery semantics#

Need Use
Loss acceptable At-most-once
Business events At-least-once + idempotent consumer
Kafka → process → Kafka Exactly-once (transactions / exactly_once_v2)
DB state + event Transactional outbox + CDC
API retries Idempotency-Key

Which pattern?#

Problem Pattern
State change must emit an event reliably Outbox + CDC
Duplicates Idempotent consumer / inbox
Multi-service business transaction Saga (orchestrated for long flows)
Reserve then commit TCC / authorise–capture
Different read and write shapes CQRS
Full history and audit Event sourcing
Queue of independent jobs Kafka share group
Ordered stream per entity Consumer group, keyed by entity
Real-time aggregates and alerts Flink / Kafka Streams with event time

Consistency cheat sheet#

Term One-liner
Linearizable Behaves like one copy, in real-time order
Causal Causes are seen before effects
Read-your-writes You see your own updates
Eventual Replicas converge when writes stop
CAP Under a partition: C or A
PACELC Else: latency or consistency
Quorum R + W > N
Raft Majority commit; 3 or 5 nodes

Iceberg Delta Hudi

Data protection techniques#

Technique Reversible Typical use
Encryption (AES-GCM) Yes (key) At rest, in transit, fields
Tokenisation Via vault only PAN, IDs, PCI scope reduction
FPE Yes Legacy format constraints
Static masking No Test data
Dynamic masking View only Analysts
Keyed hashing No Joins without revealing values
Crypto-shredding Deletes access Erasure from immutable stores

STRIDE → controls#

Threat Control
Spoofing MFA / passkeys, mTLS, workload identity
Tampering TLS, signatures, MACs, validation, immutable logs
Repudiation Signed audit logs, SCA evidence
Information disclosure Authorisation per object, encryption, masking
Denial of service Rate limits, quotas, autoscaling, WAF
Elevation of privilege Least privilege, ABAC, sandboxing
