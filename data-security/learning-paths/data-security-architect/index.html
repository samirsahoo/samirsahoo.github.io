Data & Security Architect Learning Path

Every article in a deliberate order: Kafka and event-driven design, consistency and sagas, data platforms and governance, then threat modelling, security, AI security and regulation. About three weeks at one to two hours a day.

  • For: Architects, senior engineers, data engineers and security engineers, especially in financial services
  • 21 steps · 21 available now

This path takes you from the event log to a secure, regulated, end-to-end platform design. Each step builds on the previous one. The case studies at the end of each module combine what you have learned into a complete design.
